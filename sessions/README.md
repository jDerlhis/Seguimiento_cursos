# Sesiones HSEC

Aquí se guarda la sesión de Playwright tras un login exitoso.

- Archivo: `hsec_storage_state.json` (cookies y estado del navegador)
- No subir este archivo a git (contiene datos de sesión)

Para borrar la sesión: usa **Cerrar sesión** en la app o elimina `hsec_storage_state.json`.
